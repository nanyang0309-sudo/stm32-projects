## 一、产品概述

X-LOCK S1 是一款基于 STM32 微控制器的智能指纹门锁控制系统，采用 ZW101 电容式指纹传感器与 MG996R 高扭矩舵机，支持指纹识别、密码解锁双重认证，内置管理员分级权限及防暴力破解锁定机制，适用于实验室门禁、文件柜、储物柜等场景。

## 二、技术规格

| 项目 | 参数 |
|---|---|
| 产品型号 | X-LOCK S1 |
| 主控芯片 | STM32F103C8T6 (ARM Cortex-M3, 72MHz) |
| 指纹传感器 | ZW101 电容式，256 级灰度，508 DPI |
| 指纹容量 | 99 枚（ID 1~99） |
| 识别速度 | ≤ 300ms（1:N 全库检索） |
| 误识率 (FAR) | < 0.001% |
| 拒真率 (FRR) | < 1.0% |
| 显示屏 | 0.96 英寸 OLED，128×64 像素，白光 |
| 驱动舵机 | MG996R，堵转扭矩 15kg·cm (6V) |
| 开门角度 | 80°（可固件调整） |
| 开门保持 | 3 秒后自动复位 |
| 按键数量 | 3 键（K1/K2/K3） |
| 状态指示 | 双色 LED（绿=通过 / 红=拒绝） |
| 管理密码 | 4 位数字，掉电保持 |
| 安全锁定 | 连续 5 次失败 → 锁定 60 秒 |
| 工作电压 | 5V DC（舵机需独立供电 ≥2A） |
| 通信接口 | UART (指纹模块)，PWM (舵机)，I²C (OLED) |
| 固件版本 | v2.0 (Security Enhanced) |

## 五、快速入门

### 第一步：上电启动

接通 5V 电源后，系统将在 3 秒内完成自检：

```
  ┌──────────────────┐
  │ System Init...   │   ← 自检画面
  │                  │
  │  (舵机归零)      │
  │  (指纹模块初始化)│
  └──────────────────┘
```

初始化完成后自动进入主菜单。

### 第二步：修改管理员密码（重要）

> ⚠️ **出厂默认密码：`1 2 3 4`。请务必在首次使用时修改！**

```
主菜单 → 按 K1 选中 "3.Admin" → K3 确认
       → 输入出厂密码 1234 → 进入管理员菜单
       → K1 选中 "3.Change PWD" → K3 确认
       → 输入旧密码 → 输入新密码 → 再次输入新密码确认
       → "Password Changed!" 修改成功
```

### 第三步：录入指纹

```
管理员菜单 → K1 选中 "1.Enroll Finger" → K3 确认
           → 按屏幕提示，同一手指按压两次
           → "Enroll Success!" 录入成功，ID 自动递增
```

### 第四步：日常使用

```
主菜单 → "1.Fingerprint" → 放手指 → 门开
主菜单 → "2.Password"    → 输密码 → 门开
```

## 七、功能详解

### 7.1 指纹解锁

```
  ┌──────────────────┐     ┌──────────────────┐
  │ [FINGERPRINT]    │     │ Access Granted!  │
  │ Place Finger...  │ ──→ │ ID: 01           │
  │                  │     │ Score: 98        │
  │ K3:Back          │     │ [Unlocking...]   │
  └──────────────────┘     └────────┬─────────┘
                                    │
                                    ▼
                           ┌──────────────────┐
                           │ 舵机 80° 开门    │
                           │ 绿灯亮 3 秒      │
                           │ 自动归零关门     │
                           └──────────────────┘
```

- 指纹匹配成功 → ResetFailedAttempts() → 显示 ID + Score → 绿灯亮 → 舵机开 80° 保持 3 秒 → 归零关门
- 指纹匹配失败 → RecordFailedAttempt() → 红灯亮 2 秒 → 退回等待界面

### 7.2 密码解锁（后备开锁）

```
  ┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
  │ Password Unlock  │     │ Enter 4-digit:   │     │ Access Granted!  │
  │ Enter 4-digit:   │     │  1^ 2  3  4      │     │ Password OK      │
  │  0  0  0  0      │ ──→ │  ← 光标当前位置  │ ──→ │ [Unlocking...]   │
  │ K1:+ K2:OK K3:Esc│     │ K1:+ K2:OK K3:Esc│     └──────────────────┘
  └──────────────────┘     └──────────────────┘
```

> 密码解锁与管理密码相同，作为指纹传感器故障时的备用开门手段。

### 7.3 管理员系统

```
  ┌──────────────────┐
  │ 主菜单           │
  │ 3.Admin ────────→│ 输入管理员密码
  └──────────────────┘        │
                    ┌─────────┴─────────┐
                    │                   │
               密码正确             密码错误
                    │                   │
                    ▼                   ▼
          ┌──────────────┐    ┌──────────────┐
          │ 管理员菜单    │    │ 退回主菜单    │
          │              │    └──────────────┘
          │ 1.录入指纹   │
          │ 2.清空指纹库 │
          │ 3.修改密码   │
          │ [K2:退出]    │
          └──────────────┘
```

### 7.4 安全锁定机制

```
  失败次数累计
       │
   1 ── 2 ── 3 ── 4 ── 5 ──→ ┌──────────────────────┐
                               │    !!! LOCKED !!!    │
                               │   Too many fails     │
                               │   Wait: 60s          │
                               │   (红灯常亮)         │
                               └──────────┬───────────┘
                                          │
                                    60秒倒计时结束
                                          │
                                          ▼
                               ┌──────────────────────┐
                               │   Lock Released      │
                               │   System Ready       │
                               │   (失败计数归零)     │
                               └──────────────────────┘
```

| 参数 | 值 |
|---|---|
| 失败阈值 | 5 次（指纹 + 密码累计） |
| 锁定时长 | 60 秒不可中断 |
| 锁定范围 | 所有开锁方式全部禁用 |
| 解锁方式 | 仅可等待倒计时结束 |

### 7.5 清空指纹库

```
  管理员菜单
  "2.Clear Library"
       │
       ▼
  ┌──────────────────┐
  │  !! WARNING !!   │
  │ Clear ALL prints?│
  │ K1:Yes  K3:No    │
  └────┬────────┬────┘
       │        │
      K1       K3
       │        │
       ▼        ▼
  全部删除   放弃操作
  ID重置为1
```

## 八、状态指示灯

| 状态 | 绿灯 (PA0) | 红灯 (PA1) | 说明 |
|---|---|---|---|
| 待机 | ○ 灭 | ○ 灭 | 正常待机，等待操作 |
| 验证通过 | ● 亮 3秒 | ○ 灭 | 指纹匹配或密码正确 |
| 验证失败 | ○ 灭 | ● 亮 1.5秒 | 指纹不匹配或密码错误 |
| 录入成功 | ☆ 闪 3次 | ○ 灭 | 新指纹录入完成 |
| 清库成功 | ☆ 交替闪 | ☆ 交替闪 | 双灯交替闪烁 4 次 |
| 系统锁定 | ○ 灭 | ● 常亮 | 防暴力破解锁定中 |
| 改密成功 | ☆ 闪 3次 | ○ 灭 | 密码修改完成 |

● 常亮　☆ 闪烁　○ 熄灭

## 九、故障排除

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 通电后屏幕不亮 | 供电接触不良 / 电压不足 | 检查 5V 供电，更换 USB 线或电源适配器 |
| 指纹按了没反应 | ZW101 模块未初始化 | 断电重启，确认 PA2/PA3/PA4 接线正确 |
| 舵机不转 / 只转一半 | 供电不足 (MG996R 需 ≥2A) | 舵机红黑线接独立 5V/2A 电源，地与 STM32 共地 |
| 识别率低 / 频繁拒真 | 手指太干/太湿/有污渍 | 清洁手指，重新录入指纹 |
| 忘记管理员密码 | — | 重新烧录固件恢复出厂设置 (1234)，或拔掉 VBAT 电池后断电重启 |
| 指纹 + 密码全失灵 | 系统进入锁定模式 | 等待 60 秒自动解除 |
| OLED 花屏 / 卡死 | 静电干扰或 I²C 冲突 | 按 RST 复位键重启 |

## 十、安全声明

1. **出厂密码务必修改**：默认密码 `1234` 为公开信息，首次使用请立即修改。
2. **独立供电**：MG996R 舵机不可从 STM32 板载引脚取电，否则可能损坏主控。
3. **物理安全**：本产品为电子控制组件，外部锁体结构需用户自行确保机械强度。
4. **备用方案**：建议配置物理钥匙备份，以应对电子系统完全失效的极端情况。
5. **固件更新**：请从官方渠道获取固件，擅自修改可能导致安全机制失效。
